# Chargekeeper 1.1.0

The first public release of Chargekeeper: battery charge limits, battery health, usage history and a
live system monitor for Linux laptops, as a GTK 4 / libadwaita app with a tray icon, a small
background service and a command-line tool.

## New in this version

- **Monitor update speed.** Choose every 0.5, 1, 2 or 5 seconds from a menu on the Monitor tab. The
  default is now 1 second (it was 2).
- **Smooth animation.** Numbers, bars and graphs glide between readings. You can switch it off.
- **The installer asks who made your laptop.** Pick from a menu, or skip it with a flag such as
  `sudo ./install.sh --acer`. Choosing Acer builds the driver it needs.
- **Power from charger and battery** on the Overview, Monitor, tray and command line.
- **A steadier Monitor tab,** with fixed layout, steady top-app lists and round graph scales.

See `CHANGELOG.md` for everything else, including several bug fixes.

## Install

Needs GTK 4.14+ and libadwaita 1.5+: Ubuntu 24.04 or newer, Debian 13, Fedora 40 or newer, Arch Linux,
openSUSE Tumbleweed.

```sh
tar -xzf chargekeeper-1.1.0.tar.gz
cd chargekeeper-1.1.0
sudo ./install.sh
```

Which laptops can limit charging depends on the maker and the kernel. See
"Supported laptops" in the README. Most HP, Surface, Razer and Gigabyte models have no charge control
in Linux and get an unplug reminder instead. The reference laptop is an Acer Predator PH315-55; other
makers' firmware rules are checked by tests that emulate the kernel, so reports from other laptops
are very welcome.
